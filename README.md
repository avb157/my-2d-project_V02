# My Platformer

> Динамичный 2D-платформер с паркуром, wall jump'ами, перекатами и анимированным ночным городом.

## Особенности

- **Полноценная физика**: двойные прыжки, wall jump, перекаты, лазание по стенам
- **Плавные анимации**: 4–6 кадров в секунду для выразительности
- **Атмосферный уровень**: ночной город с мерцающими неоновыми огнями
- **Система прогресса**: таймер, здоровье, экран победы
- **UI**: главное меню, пауза, экран смерти и победы

## Как запустить

### Требования
- Python 3.13
- Pygame
- VS Code (с расширением Python)

### Установка
1. Скачайте репозиторий
2. Распакуйте проект в папку
3. Создайте виртуальное окружение (рекомендуется):
    # Windows
    python -m venv venv

    # macOS / Linux
    python3 -m venv venv
4. Активируйте окружение:
    # Windows
    venv\Scripts\activate

    # macOS / Linux
    source venv/bin/activate
5. Установите зависимости:
    pip install -r requirements.txt #Такой вариант благодаря наличию "requirements.txt"
6. Выберите интерпретатор Python в VS Code:
    6.1. Нажмите Ctrl+Shift+P (Windows/Linux) или Cmd+Shift+P (Mac)
    6.2. Введите: Python: Select Interpreter
    6.3. Выберите путь к Python внутри папки venv
7. Запустите игру
